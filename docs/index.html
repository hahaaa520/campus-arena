它解决什么问题三个具体痛点

1

算对阵麻烦

支持单循环 / 双循环 / 单败淘汰 / 小组赛+淘汰赛四种赛制，自动生成完整对阵，含轮空与交叉淘汰席位。

2

排时间容易撞

贪心排期自动满足三条硬约束：同一场地同一时刻只有一场、同一队伍同一时刻只有一场、同队两场间隔不小于设定值。

3

改一处要重排全表

冲突检查分「必须修复」与「建议调整」两级，逐条给出中文说明；个别场次可手动调整并锁定，重新排期时保持不变。

怎么跑起来构建与测试

需要 DevEco Studio 5.0.13 及以上（内含 HarmonyOS SDK 5.0.5 / API 17、hvigor 5.17.6）。

REM 1) 编译，产出 HAP
tools\build.cmd assembleHap --no-daemon

REM 2) 打包，产出可上架的 .app
tools\build.cmd assembleApp --no-daemon

REM 3) 核心算法测试（50 项）
tools\logic-test\run-tests.cmd

REM 4) 全量校验（编译 + 打包 + 测试 + 产物检查）
tools\verify-all.cmd

在 DevEco Studio 里直接打开本工程，用预览器或模拟器即可看到界面 （入口页 entry/src/main/ets/pages/Index.ets）。
